## 🎯 Sobre

Este repositório reúne os trabalhos realizados por **Guilherme** na disciplina de **Interface e Jornada do Usuário**, ministrada pelo **Prof. Paulo Fratta**.

O foco é entender como as pessoas interagem com produtos digitais e projetar interfaces claras, acessíveis e centradas no usuário. Cada trabalho tem sua própria pasta, com um README explicando o objetivo, o desenvolvimento e o resultado.

## 🧠 Conteúdo abordado

- 👥 Pesquisa com usuários e criação de **personas**
- 🗺️ **Jornada do usuário** (pontos de contato, dores e oportunidades)
- ✏️ **Wireframes** e fluxos de navegação
- 🖥️ Design de **interface (UI)**: cores, tipografia, componentes e hierarquia visual
- ♿ Usabilidade e acessibilidade
- 🧪 **Protótipos** e testes de usabilidade
